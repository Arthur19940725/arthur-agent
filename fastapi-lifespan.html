进程生命周期钩子

把 FastAPI 想成一家餐厅：开门前备菜，营业中接客，关门时收拾。lifespan 就是这套开店—营业—打烊流程。

↗
↘

请求到来前后，发生什么？

1

启动 startup

应用开门。加载模型、连接数据库、准备缓存。

2

服务中

门开着。FastAPI 接收并处理请求。

3

关闭 shutdown

应用打烊。断开连接、释放资源、清理缓存。

这行代码到底在说什么？

FastAPI(...)

创建一个 FastAPI 应用，就像开一家餐厅。

lifespan=lifespan

把名为 lifespan 的“开门和打烊流程”交给它管理。不是立刻执行，而是告诉应用：启动和关闭时请调用它。

FastAPI(
    title="arthur-agent API", # 餐厅名字：显示在 API 文档里
    lifespan=lifespan       # 开门/打烊说明书
)

记住一个词：yield

yield 前 = 开门准备

代码先跑完，服务才开始接客。

yield 后 = 打烊清理

服务停止后，代码从这里继续跑。

from contextlib import asynccontextmanager
from fastapi import FastAPI

@asynccontextmanager
async def lifespan(app: FastAPI):
    # 开门：加载资源
    db = await connect_database()
    yield
    # 打烊：释放资源
    await db.close()

app = FastAPI(lifespan=lifespan)
一句话：yield 上面准备，yield 下面清理。
现在推荐使用 lifespan；旧的 @app.on_event("startup") / shutdown 方式已不推荐。
